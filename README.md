# ⏳ Les Boucles du Sablier

Jeu incrémental à boucle temporelle, dans le navigateur. Le héros revit la même journée : il oublie tout à chaque boucle, mais le village, lui, se souvient.

**Jouer :** https://steven-moire.github.io/boucles-du-sablier/

## Ce qu'il y a dans le prototype (v0.3)
- Carte à cases façon PowerSeeker : 2 biomes, élites, boss, récolte, sources, trésor.
- Combats automatiques en vagues, compétences qui se déclenchent seules, retraite possible.
- Boucle de 75 s : à la mort ou à la fin du temps, retour au village.
- Progression permanente : village (Entraîneur, Forge, Horloge), bestiaire, trophées uniques.

## Déployer sur GitHub Pages
1. Crée un dépôt `boucles-du-sablier` et pousse ce dossier sur la branche `main`.
2. Dans *Settings → Pages* : Source = *Deploy from a branch*, branche `main`, dossier `/ (root)`.
3. L'URL apparaît au bout d'une minute environ. Chaque push sur `main` met le jeu à jour.
